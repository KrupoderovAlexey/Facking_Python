========================> ПЛАН РАБОТЫ <========================

1: Разведочный анализ и знакомство с данными (EDA)
  ->  Оценка количества строк и столбцов, оценка типов данных, проверка на полное дублирование строк
  
2: Предобработка и очистка данных
  ->  Изменение типов данных
      ->  Обработка аномалий: Выявите экстремальные значения (аутлайеры)
      ->  Удаление в случае опечатки
      ->  Замена на медиану
      ->  Оставить и анализировать отдельно
  ->  Обогащение данных
      ->  Рассчитайте время доставки как разницу между Ship Date и Order Date
      ->  Выделите из дат месяц и квартал для анализа сезонности
      
3: Исследование базовых бизнес-метрик
  ->  Общие итоги
      ->  Рассчитайте суммарный оборот (Sales), общую чистую прибыль (Profit), суммарное количество проданных товаров (Quantity ordered new) и средний размер скидки (Discount)
  ->  Метрики эффективности
      ->  Посчитайте общую рентабельность продаж (отношение прибыли к выручке)
      
4: Анализ продуктовой матрицы и категорий
  ->  Категориальный анализ
      ->  Сгруппируйте данные по Product Category и Product Sub-Category. Оцените выручку и прибыль для каждой группы
  ->  Поиск «черных дыр»
      ->  Определите категории или конкретные продукты (Product Name), которые приносят наибольшие убытки (отрицательный Profit)
  ->  Анализ маржинальности
      ->  Сопоставьте показатель Product Base Margin с реальной полученной прибылью по подкатегориям
5: Анализ клиентов и сегментов
  ->  Сегментация
      ->  Сгруппируйте данные по Customer Segment (Corporate, Home Office, Small Business, Consumer). Выясните, какой сегмент генерирует основной доход, а какой наиболее стабилен
  ->  Концентрация клиентов
      ->  Посмотрите на распределение продаж по Customer ID / Customer Name, чтобы понять, зависят ли продажи от нескольких крупных клиентов или распределены равномерно
      
6: Пространственно-временной анализ (География и Тренды)
  ->  Географический срез
      ->  Сгруппируйте показатели по регионам (Region), штатам (State or Province) и городам (City). Найдите самые прибыльные и самые убыточные локации
  ->  Динамика продаж
      ->  Постройте тренд изменений Sales и Profit по месяцам/кварталам. Определите пиковые периоды активности и спады
      
7: Анализ операционных процессов и логистики
  ->  Эффективность доставки
      ->  Сгруппируйте данные по типам доставки (Ship Mode). Посчитайте среднюю стоимость (Shipping Cost) и среднюю скорость доставки для каждого типа
  ->  Влияние приоритета на логистику
      ->  Проверьте, коррелирует ли Order Priority (Critical, High, Medium, Low) с реальной скоростью отправки товаров
  ->  Анализ типов контейнеров
      ->  Посмотрите, как Product Container влияет на стоимость транспортировки (Shipping Cost)
      
8: Изучение взаимосвязей
  ->  Влияние скидок
      ->  Проанализируйте зависимость между величиной скидки (Discount) и объемом заказа, а также влиянием скидки на финальную прибыль (не уходят ли сделки с большими скидками в глубокий минус)
  ->  Взаимосвязь стоимости и объема
      ->  Оцените, как цена за единицу (Unit Price) влияет на заказываемое количество (Quantity ordered new)
      
9: Формулирование выводов и рекомендаций
  ->  Сведите инсайты в единый отчет
      ->  Зафиксируйте топ-3 драйверов роста компании и топ-3 главных источников убытков
  ->  Разработайте рекомендации
      ->  Сформулируйте бизнес-советы (например: «изменить условия работы с убыточным сегментом Х», «оптимизировать доставку типа Y в регион Z», «пересмотреть политику предоставления скидок на товары с низкой маржой»)
